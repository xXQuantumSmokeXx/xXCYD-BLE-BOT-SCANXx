## Ideas

- **Known-device memory** — hashed MAC list in NVS so a device flagged earlier still
  shows as known after a reboot.
- **MAC rotation tracking** — group entries by (name, company id) to spot the same
  device reappearing under a new random address.
- **Sort by class / vendor**, filter to cameras or wearables only.
- **RSSI history sparkline** on the detail screen.
- **Alert log** — record when a watchlisted device enters range.
- **Adjustable scan duty cycle** (currently 100 ms / 99 ms) to trade power for reach.
- **Classic-only mode** for devices that never advertise over BLE.
- **Field notes** — user-editable label per device.

## Known issues / watch items

- **SPI bus sharing is the fragile part of this project.** Display + SD + touch all end
  up on VSPI; any new SPI peripheral must account for the touch pin map or it will
  silently kill touch input.
- Classic BR/EDR finds are unverified — the stack comes up but no classic device has
  been captured. Worth a walk-around test.
- Format/argument mismatches are now build errors (`-Wformat=2 -Werror=format`). One shipped in
  v1.1-era builds: a `%s` was added to the JSON format without its argument, printing garbage
  and faulting. If a build suddenly fails on `format-truncation`, size the buffer rather than
  dropping the flag.
- `pio run` occasionally reports a spurious `In file included from ...` error on the
  first invocation and builds fine on retry.
- 1-USB env has not been rebuilt since the layout work; rebuild before flashing it.
- Flash is healthy (2.94 MB app, ~42.6% used); the generated tables are the bulk
  (OUI ~65 KB, company ids ~63 KB).

## Completed

- **BLE device names fixed** — `wantDuplicates=true`; names in the scan response were
  being dropped as duplicates.
- **UTF-8 name sanitising** — non-ASCII stripped; empty result falls back to MAC tail + `*`.
- **Vendor tables** — full IEEE OUI (16,327 prefixes / 193 vendors) and SIG company ids
  (4,057), both generated by `tools/gen-*.mjs`.
- **Company-id fallback** — names devices with randomised MACs.
- **Address-type badge** — `P` / `R` for stable vs rotating addresses.
- **Layout** — dim row separators removed; list centred vertically; row cluster centred
  on the widest row so bars sit beside their numbers; vendor next to the name.
- **Top bar** — debug counter and `+BT` badge removed; `SHIELD UP` has the right side.
- **Detail screen** — tap a row for the full record; tap again to close.
- **List paging** — swipe up/down pages by (visible − 1); scrollbar, `x-y / N` readout,
  clamped at both ends, row taps resolve through the scroll offset.
- **JSON capture** — one line per new device, BLE and classic, `J` toggles.
- **Bus conflict solved** — never call `SPI.begin()` after `tft.init()`; touch moved to its own peripheral (HSPI), display + SD on VSPI.
- **SD logging** — working: 4 KB buffer, 2 s flush, `/ble.jsonl`, `L` toggle, boot banner.
- **Log quality** — one line per MAC per boot (dedupe by RAM set), names trimmed of
  stray whitespace, logged after parsing so the name is present, first 128-bit service
  UUID captured as `u128`.
- **Partition table** — single 2.94 MB app, no OTA; NVS preserved at 0x9000.
- **Footprint trim** — dropped unused TFT fonts 6/7/8 and the smooth-font engine.
- **merge_bin.py hardened** — ASCII output, UTF-8 stdout, boot_app0 at 0xe000.
- **Docs** — README.md, FEATURES.md, TODO.md.
- **Detection signature engine** — JSON rules -> generated header, matched on every
  packet, label shown in the row and detail screen and logged as `sig`.
- **Corpus analyser** — `tools/analyze-corpus.mjs` proposes signatures from `ble.jsonl`.
- **Payload dump** — one hex dump per new device, `H` toggles, decoded by `tools/decode-adv.mjs`.
